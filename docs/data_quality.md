# качество данных

## что проверил и всё в порядке

- `ID_Чека` уникален, карты в справочнике тоже 
- пустых дат нет, стоим. чека везде больше нуля
- согласие на Email и SMS только 0 и 1
- все карты из покупок и из бонусов есть в справочнике, все типы транзакций тоже
- по месяцам сходится: карт 96 + 1 + 3 = 100

## что нашёл
- в 450 чеках из 500 нет номера карты, => средний чек по 50 чекам, а в некоторые месяцы по одному-двум. его динамике верить нельзя
- 96 карт из 100 выданы в январе 2022, последняя в июне
- Email есть у 63% карт, SMS у 33%, main - почта
- начислено 22 720 баллов, сгорело 90 001, корректировок на +86 800, в марте сгорание и корректировки почти совпали (40 630 и 42 300), в остальные месяцы нет, нужно уточнить у владельца данных
